# Page 7 — Move-In Checklist Printables

*A fan-made guide by Asdale Dynamics, LLC — unofficial, unaffiliated, ad-free,
no account data, no sign-ups.*

This page is two things: a **movement plan** for the hour after you get the
keys, and a set of **printable checklists** built for the kind of night where
you finally have the plot and immediately can't remember what you were going
to do next.

Everything here is copy-paste friendly. Markdown tables, plain-text blocks —
take them, print them, scribble on them.

## 1. The "got the keys" hour (a quick-start list)

Do these in order; each takes about a minute:

1. **Open the housing menu and read everything once.** Menus hide features;
   the first hour is the cheapest time to find them.
2. **Locate your storage.** Know where spare furniture goes *before* you start
   swapping things.
3. **Use the exterior fixtures.** Door, outer walls, roof. A house with no
   door reads as a very committed cave.
4. **Find your permit** (usually a ticket item in your inventory). Keep it.
   It is proof; it does nothing useful on the Market Board.
5. **Set the welcome message** on your placard/entrance, if you want one.
   Short and warm beats clever.
6. **Light the place** — interior lighting items first; mood does the rest.
7. **Take one screenshot.** The "before" photo is the whole point of belonging
   somewhere — you'll want it in a year.

## 2. Printable checklist — session 1 (the same night)

```plain
MOVE-IN, SESSION 1 — date: ______

[ ] Plot purchased           [ ] Permit purchased
[ ] Door installed           [ ] Exterior walls/roof set
[ ] Interior walls set       [ ] Interior floor set
[ ] Interior lighting set    [ ] At least one lamp on
[ ] Bed placed               [ ] Retainer bell placed
[ ] One chair + one table    [ ] Storage located (know where it is)
[ ] Welcome message set      [ ] Screenshot taken

One thing I wish I'd known during session 1:
______________________________________________________________
```

## 3. Printable checklist — session 2 (the tidy-up weekend)

```plain
MOVE-IN, SESSION 2 — date: ______

[ ] Save-a-layout used (if you've arranged a room you like)
[ ] Windows placed (a real window, not a wallpaper window)
[ ] Indoor planter placed and seeded        (see Page 3)
[ ] Fencing placed around the yard, if applicable
[ ] Garden patch placed and seeded          (see Page 3)
[ ] Chocobo stable placed, if you have a bird
[ ] Mannequin dressed                       (see Page 5)
[ ] One rug that ties the colour story together
[ ] War room check: does every item have a named home? (see Page 2)
[ ] Repair ritual date picked and logged    (see Page 6)
[ ] Invite a neighbour over. Actually — this one's not skippable.

What still feels unfinished after session 2:
______________________________________________________________
```

## 4. Printable checklist — the "guest visit" pass

Run this once before the first person sees the house. It's the checklist
version of looking in the mirror before leaving:

```plain
GUEST-VISIT PASS — date/time of visit: ______

[ ] Entry path is clear (no furniture in the door)
[ ] Lights are actually on
[ ] A chair they can sit in
[ ] One topic-piece to look at (a garden, a shelf, a scene)
[ ] Welcome message current
[ ] Nothing in the yard that embarrasses you
[ ] Fresh water in the indoor planter (guests notice!)

Guest who visited: ______ (game name only — no real names in notes)
Something they liked: ______
```

## 5. A note about "printables"

Everything in this page is plain text on purpose, so it works if you:

- print it on actual paper,
- paste it into any notes app on any device,
- share it as text in an FC forum thread.

There is no special app here, no account, no sync service. If you ever need to
move the checklist to a different tool, it will survive the trip — that's the
point of plain text.

## For tomorrow

Do the session-1 checklist as far as you can tonight, and set a date (next
weekend?) for session 2. Deadlines you set for yourself are the only housing
deadlines that exist.
