# Page 6 — Repair Timer Logs

*A fan-made guide by Asdale Dynamics, LLC — unofficial, unaffiliated, ad-free,
no account data, no trackers.*

Gear degrades. Repairs cost gil (or dark matter, if your friends are crafters).
And because repairs happen in the middle of doing something *fun*, nobody ever
wants to stop and write down when they last did one.

That's exactly why a **repair timer log** helps. Not because repairs are
complicated — because memory is.

## 1. How gear repair works for non-crafters

- Every piece of gear has a **condition** percentage that drops as you use it.
  Lower condition means weaker gear; very low condition means it will break.
- **Non-crafters repair via NPCs.** Repair NPCs in the major cities (and in
  some field locations) open a repair window where you pick the gear in your
  bags (or on your person) and pay in gil.
- **Crafters can self-repair** using dark matter. If you have an FC-mate who
  does this, offer to trade: it's usually cheaper for everyone.
- **When to repair:** opinions differ. Repairing around the 30–50% range keeps
  you safe without wasting gil; waiting until gear is nearly broken is where
  emergency repairs bite.

## 2. What the log is for

A repair timer log answers three questions at a glance:

1. **How often does my gear actually degrade?** (Per hour of duty? Per raid?)
2. **How much is this costing me per week?** (So you can budget gil.)
3. **Is a particular role letting gear degrade faster?** (If your tank gear
   degrades twice as fast as your healer gear, that tells you something.)

It also answers the "did I already repair that?" question, which is the one
that saves real embarrassment mid-dungeon.

## 3. The printable log

Copy this table into a text note, a spreadsheet, or a paper notebook. Print
several per session — it takes about ten seconds per row to fill in.

```plain
REPAIR TIMER LOG — Player: ______ Server(home world): ______
(date and world are optional; never store real personal data here)

Date   | Time  | Character | Gear slot set   | Condition start | Cost (gil) | Repairer type | Notes
-------|-------|-----------|-----------------|-----------------|------------|---------------|-------
       |       |           |                 |                 |            |               |
       |       |           |                 |                 |            |               |
       |       |           |                 |                 |            |               |

WEEKLY TOTALS
Gil spent on repairs: ______
Repairs done (count): ______
Condition range at repair (min / max): ______ / ______
Notes for next week: ______
```

### How to fill it in

- **Gear slot set:** "full kit", "tank set", "the level 90 set" — anything you
  will recognise.
- **Condition start:** the percentage the gear was at when you decided to
  repair. Over time, you'll see your own habits.
- **Repairer type:** NPC, FC crafter, dark matter, or "hoped it would survive"
  (log that one honestly — it's the most instructive row in the table).
- **Notes:** anything odd. "Repairer was busy", "ran out of gil", "FC friend
  repaired free — remember to trade them a favour next week".

## 4. Reading your own log after two weeks

Patterns the log usually reveals, in rough order of how often we've seen them:

1. **"I repair far more often than I thought."** Good — that's the point. Most
   non-crafters under-budget for this.
2. **"The gear I wear in raids dies first."** Substitution helps: logout in a
   "playing-around set" rather than in your best raiding kit.
3. **"Spikes right before big content releases."** i.e., you repair
   reactively. Setting a weekly repair *ritual* (after roulettes, say) smooths
   this out.
4. **"My costs are tiny, honestly."** Also a valid result — now you *know*.

## 5. A weekly ritual that fits on a sticky note

Once a week (pick a day; we suggest one tied to an in-game reset you already do):

- Run the repair NPC once, top up everything to full.
- Fill in the weekly totals row.
- Refill anything you used.
- Done. Total time: about 90 seconds.

## For tomorrow

Set up one line of the log. You don't need a system — you need a line, and one
row after next dungeon. Everything else grows from that.

**Printable tip:** if you keep this on your phone, paste the block into a
notes app as-is; the formatting usually survives a copy-paste surprisingly
well. For a paper version, just print it and keep it near your keyboard.
